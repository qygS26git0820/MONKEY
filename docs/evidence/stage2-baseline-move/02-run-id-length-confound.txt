# 一条方法论发现：run_id 长度会改变被观测到的字节数

第一版比较用了前缀 ab-local-（9 字符）对 mv-（3 字符），结果每组失败场景的
verification.stderr_stream 都多出 12 字节差。原因不是行为变了，是：

  失败回溯里含工作区绝对路径，路径里含 run_id；run_id 短 6 字符，
  路径在回溯里出现两次，于是 bytes_total / bytes_delivered 各少 12。

tests/test_determinism.py 不受此影响，因为它的两条 run 用等长 run_id（t- + 10 位十六进制）。

后果（值得记）：**run_id 长度是流字节数的一个混杂项**。跨 run 比较
bytes_total / bytes_delivered 时 run_id 长度必须相同，否则差异里混进了与
agent 行为无关的成分。第 01 份证据的两批 run 前缀等长（各 9 字符），
就是为了消掉这个混杂项。
